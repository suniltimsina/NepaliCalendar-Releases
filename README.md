# Nepali Calendar Pro

> A comprehensive BS/AD calendar, date converter, date injector, and number-to-words tool for Windows.

[![Platform](https://img.shields.io/badge/Platform-Windows-blue.svg)](#)
[![Status](https://img.shields.io/badge/Status-Early_Access-orange.svg)](#)

---

## 📥 Download & Install

You do not need Python or any special software to run this app. 

1. Go to the [Releases Tab](../../releases/latest) on the right side of this page.
2. Download **`NepaliCalendarPro_Setup_v1.1.0.exe`**.
3. Double-click to install and enjoy!

---



## ✨ Features

| Tab | What it does |
|---|---|
| **Calendar** | BS & AD month view, holiday highlights, custom scrollable year dropdown, click to inject dates globally |
| **Calculators** | Date math (add/subtract Y/M/D), Age Calculator mode, and date difference |
| **Ranges** | Generate a list of dates between two dates |
| **Converter** | BS ↔ AD date conversion |
| **Numbers** | 4-tab conversion system: International, Nepali English, Devanagari, and Unicode formats |

### 🚀 Advanced Capabilities

- **Smart Capture (Alt+Q)**: Automatically captures dates or numbers from any active window (like Excel, Word, or browsers), parses them, and routes them to the correct tab in the app.
- **Desktop Widget**: A sleek, draggable desktop widget that floats on your screen to always display today's date. Double-click it or right-click to instantly copy the date in Nepali or English.
- **Global Toggle (Alt+D)**: Instantly show or hide the application from anywhere.
- **Global Key Injection**: Injects dates and numbers directly into any text field or spreadsheet.
