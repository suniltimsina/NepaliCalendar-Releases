# Nepali Calendar Pro

A comprehensive BS/AD calendar, date converter, and number-to-words utility built specifically for Windows. It runs quietly in your system tray and integrates directly into your daily workflow.

Built with Vibe Coding — but designed to get real work done.  
(Yes, it actually works. Ha ha.)

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://python.org)

---

## ⚡ Features

### 📅 Interactive Calendar
- BS (Bikram Sambat) and AD (Gregorian) calendar side-by-side
- Public holidays and festival highlighting
- Click-to-insert dates into external apps
- Smooth year navigation

### 🧮 Date Calculators
- Add/Subtract years, months, days
- Exact date difference calculation
- Age calculator with precision breakdown
- Fully synchronized BS & AD support

### 📋 Date Ranges
- Generate continuous date sequences
- Ideal for Excel and reporting tasks

### 🔄 Date Converter
- Instant BS ↔ AD conversion
- Direct insertion into Word/Excel

### 🔢 Number to Words
- Converts numbers into:
  - International system (Million/Billion)
  - Nepali system (Lakh/Crore)
  - Devanagari (नेपाली)
  - Unicode formats

---

## ⚡ Workflow Integration

- Smart Capture (Alt+Q): detect numbers/dates from any app
- Global Injection: send results directly to Word/Excel
- Toggle (Alt+D): show/hide app instantly
